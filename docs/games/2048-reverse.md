反向思维的 2048 挑战！从大数字开始，体验完全不同的策略和乐趣。

## 🎯 玩法说明

- 与经典版相反，从较大的数字开始
- 使用 **方向键** 或 **滑动屏幕** 移动方块
- 相同数字的方块碰撞时合并
- 尝试在方块填满之前达到目标
