## 🎯 玩法说明

- 基础玩法与经典 2048 相同
- 收集并使用 **特殊道具**：
  - 🔄 撤销：回退一步
  - 💣 炸弹：消除一个方块
  - ⭐ 翻倍：将一个方块数值翻倍
- 合理使用道具是获得高分的关键
