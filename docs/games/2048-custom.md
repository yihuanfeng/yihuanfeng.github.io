自定义棋盘大小的 2048！从 3×3 到 8×8，选择适合你的挑战难度。

## 🎯 玩法说明

- 选择你想要的 **棋盘大小**
  - 3×3：极简挑战
  - 4×4：经典模式
  - 5×5 及以上：扩展挑战
- 使用 **方向键** 或 **滑动屏幕** 移动方块
- 相同数字的方块碰撞时合并
