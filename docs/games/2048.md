经典的数字合并益智游戏。通过上下左右滑动，让相同数字的方块碰撞合并，目标是创造出 **2048** 方块！

## 🎯 玩法说明

- 使用 **方向键** 或 **滑动屏幕** 移动所有方块
- 相同数字的方块碰撞时会 **合并成它们的和**
- 每次移动后会在空白处随机生成一个新方块（2 或 4）
- 当无法移动时游戏结束
