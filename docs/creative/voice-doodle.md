终极版涂鸦画板！支持画笔、橡皮擦、撤销、继续，以及独特的 **声控绘画** 功能。

## ✨ 功能特点

- 🖌️ **画笔模式**：自由绘制
- 🧹 **橡皮擦**：擦除不需要的部分
- ↩️ **撤销/继续**：支持多步撤销和重做
- 🎤 **声控绘画**：通过声音控制画笔移动和绘制
- 📊 **实时调试面板**：显示音频分析数据

## 🎮 操作说明

| 功能 | 操作 |
|------|------|
| 绘制 | 鼠标/触摸拖动 |
| 切换工具 | 点击工具按钮 |
| 撤销 | Ctrl+Z 或撤销按钮 |
| 声控 | 允许麦克风权限后，用声音控制 |
