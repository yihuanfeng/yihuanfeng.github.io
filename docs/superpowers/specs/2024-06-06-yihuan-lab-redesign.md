# Yihuan's Lab 网站内容重构设计

**日期**：2024
**状态**：已批准

## 网站定位

- **目的**：展示编程作品 + 记录成长故事
- **感受**：有趣、亲切，让人想探索
- **受众**：想了解小朋友编程作品的人

## 网站名称

**Yihuan's Lab**

## 页面结构

### 首页 (index.md)

```
├── Hero区
│   ├── 大名：冯意欢
│   ├── 副标题：9岁 · 小学三年级 · 编程小达人
│   └── 按钮：开始探险 / 太阳系
│
├── 关于我（一句话）
│   "我叫冯意欢，今年9岁。我喜欢用代码创造有趣的东西！"
│
└── 我的作品
    ├── 标题：我的作品（共X个）
    └── 作品卡片网格（全部作品，时间排序）
        ├── 趣味游戏
        ├── 太阳系
        ├── 创意交互
        ├── 视觉效果
        └── 科学实验
```

### 关于页 (about.md)

```
├── 关于我
│   └── 一句话介绍
│
└── 我的编程故事
    ├── 🌱 开始（什么时候开始学的）
    ├── 🌿 成长（学了什么，做过什么）
    └── 🌸 未来（以后想做什么）
```

## 作品展示方式

- 首页直接展示所有作品卡片
- 按时间排序（最新在前）
- 不写死分类，方便后续添加
- 每个卡片显示：图标、名称、简介

## 设计风格

沿用 Claymorphism 设计系统：
- 淡紫色背景
- 白色圆角卡片
- Baloo 2 字体
- 紫色 + 橙色配色
