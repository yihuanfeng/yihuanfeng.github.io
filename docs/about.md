# 关于我

我叫冯意欢，今年9岁，小学三年级。我喜欢用代码创造有趣的东西！

从7岁开始学编程，到现在我已经能做各种好玩的东西了。代码对我来说就像魔法一样，能把想象变成真的。

---

## 我的编程故事

### 🌱 开始

我7岁的时候开始学编程。一开始只是觉得电脑很神奇，能做出各种东西。后来我发现，编程也可以很有趣，不只是敲代码，而是创造！

### 🌿 成长

学了两年编程，我做过了很多作品：

- 🎮 **游戏**：2048 各种版本，还有更多在计划中
- 🪐 **3D**：用 Three.js 做了太阳系，可以看到八大行星
- 🎨 **创意**：声控涂鸦、手势控制、魔法球...
- ✨ **视觉**：粒子效果、万花尺图案...
- 🔬 **科学**：把科学实验变成互动的网页

### 🌸 未来

我想以后做出更厉害的作品，学习更多编程知识。也许有一天能成为一个真正的程序员！
