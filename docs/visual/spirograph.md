电子版的万花尺（Spirograph）！通过调整参数绘制出美丽的数学曲线图案。

## ✨ 功能特点

- 📐 **参数调节**：
  - 大圆半径：40-160
  - 小圆半径：10-100
  - 画笔位置：5-60
  - 绘画速度：0.01-0.5
  - 线条粗细：0.2-4
  - 尖度：0.02-3
- 🎨 **实时预览**：调整参数即时看到效果
- 💾 **保存作品**：保存你创造的图案

## 🎮 操作说明

1. 调整滑块设置参数
2. 点击 **开始** 绘制
3. 点击 **停止** 暂停
4. 点击 **重置** 清空画布
