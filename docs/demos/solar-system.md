基于 **Three.js** 的太阳系 3D 模拟，包含八大行星及月球，支持自由视角探索。

## ✨ 功能特点

- 🌍 **真实比例**：行星大小和轨道相对比例展示
- 🌙 **月球系统**：地球-月球系统完整模拟
- 🔍 **自由视角**：拖动旋转视角，双指/滚轮缩放
- ⚡ **速度控制**：支持停止/慢速/正常/快速四种速度
- 📖 **信息面板**：点击任意天体查看详细介绍

## 🎮 操作说明

| 操作 | 功能 |
|------|------|
| 拖动 | 旋转视角 |
| 滚轮/双指 | 缩放大小 |
| 点击天体 | 查看详细信息 |
| 速度按钮 | 控制运行速度 |
